# Running The Test

A Codespace must be created before the interview, and the link shared with the candidate at
the start of the interview.

The interview team should run the ensure_env.py script in the terminal window in Codespaces
to ensure the environment is setup.

The following steps must be followed to run the test.

## Codespace

- At least 15-30 mins before the interview, open the repository on GitHub and check the main branch is blank with no spurious commits.
- Create a Codespace for the main branch.
- Once the Codespace is open, run the ensure_env.py in the terminal and make sure it completes without errors.
- Click the LiveShare icon on the bottom right to enable live sharing.
- Click the LiveShare icon on the left icon bar to open the LiveShare panel. **Create a Read/Write terminal.**
- Click on the invite participants item in the panel to copy the link to share, share with the other panel members and ensure they can open it

## Interview

- Join the interview with the candidate.
- Share your Codespace screen and give the candidate a short tour of the repository, explain the goal, explain the files they have access to and where they can work.
- Ensure you explain to the candidate to attempt all questions, and to move on if they get stuck.
- Ensure you explain to the candidate they can use the static police_api_data.json if there is an issue accessing the API.
- Explain how they can run the etl, unit tests or any python file they create themselves via the terminal.
- Check and ensure you have answered any questions from the candidate
- Stop sharing your screen and ask the candidate to share their screen (so you can see them work in Codespace)
- Ensure the person who created the Codespace keeps it focused in a tab (its been known to lag when not focused)
- Ask the candidate to use git in the terminal to create a branch based on their surname
- Ask the candidate to use git to check out their branch so they can work on it
- Ask the candidate to proceed to the tech-test

## Ending the Interview

- Ask the candidate to use git to add their changed files, and commit them to their branch
- Stop sharing screens and close the Codespace instance
