# moj_de_tech_test

The MoJ Data Engineering test.

## Contents

The project includes the following important elements:

- test_tasks.py -> Main technical test
- data/crime_severity.csv -> Data the technical test will rely on
- data/police_api_data.json -> Backup data if there is a problem with requests and the police API during the test

## Tools

The following is installed:

- Pandas
- Pytest
- Requests

You may install other packages to help complete the technical test via pip.

## Environment

The intention is to use the test within GitHub Codespaces. The .devcontainer folder pre-configures
the environment ready for the test. Codespaces provides a vscode environment for collaborative
development.
